업무에 적용한 프로젝트

실제 회사·개인 업무에서 어떤 불편이 있었고, 무엇을 만들어 어떻게 쓰고 있는지 기록합니다.

현재 업무에 사용 중

Bid Desk — 입찰목록 수집·분석 자동화

나라장터를 포함한 5개 조달 시스템의 흩어진 입찰공고를 같은 검색조건으로 통합 수집하고, 상세·첨부파일·A값까지 한 화면에서 빠르게 확인하는 입찰업무 자동화 도구입니다. 반복되는 조회와 문서 확인은 줄이고, 판단에 필요한 공고정보는 더 빠르고 정확하게 정리합니다.

업무를 바꾸는 6가지 핵심 기능

  • 5개 조달 통합 수집 — 나라장터·국방전자조달·LH·한국가스공사·코레일을 한 번에 조회
  • 코레일 물품 내자·외자 구분 검색 및 표기
  • 공고 상세·분석창 연결 — 공고번호는 상세화면, 공고명은 분석화면으로
  • 첨부파일 안전 파싱 — PDF·HWP·HWPX·XLSX·TXT 자동 확인, 손상 파일 개별 격리
  • A값 신뢰성 검증 — 명시값과 보험료 사후정산 항목 교차검산
  • Excel 저장·이동 실행 — 이식형 구성으로 다른 PC에서도 실행

🔒 보안: 기본은 실행할 때마다 로그인(선택 시 7일 유지), 비밀번호 원문 미저장, 안전한 종료·세션 정책 적용. · Windows PC · Chrome 기반

Bid Desk · 상세

수집부터 분석까지, 한 화면에서

COLLECT · ANALYZE · VERIFY · EXPORT — 공고목록 통합관리와 첨부문서 안전분석을 하나의 업무 흐름으로 묶었습니다. 실제 입찰업무 순서에 맞춰 설계해, 도구를 오가지 않고도 공고 확인과 판단 근거 정리를 마칠 수 있습니다.

  • 기관별 목록과 통합 목록을 한 화면에서 제공
  • 공고번호·기관·마감일 등 핵심정보 자동 정리
  • 대용량 파일로 인한 전체 종료 방지, 오류 파일만 격리
  • 근거 부족 시 'A값 확인 필요'로 안전 표기
업무 자동화

데이터 자동 다운로드

여러 페이지를 반복 조회하고 엑셀로 내려받던 작업을 프로그램이 대신하도록 만들었습니다. 조건만 입력하면 전체 페이지를 돌며 자료를 모으고 폴더까지 정리합니다.

  • 조건 입력 자동화
  • 전체 페이지 반복 수집
  • 다운로드 폴더 자동 정리
엑셀 도구

엑셀 대용량 병합기

흩어져 있는 여러 엑셀 파일을 하나로 합치고, 필요한 열만 골라 업무용 자료로 바로 쓸 수 있게 정리하는 도구입니다.

  • 대량 파일 병합
  • 열 이름 자동 매칭
  • 결과 파일 자동 생성
모바일 앱 · v1.0

나라장터 AI 낙찰 예측 모바일

나라장터 공공데이터를 가져오고, 첨부한 낙찰데이터를 분석해 입찰대장 엑셀까지 만드는 모바일 입찰 업무 앱입니다. PC가 없어도 현장에서 공고 확인부터 낙찰 분석, 대장 정리까지 한 번에 처리합니다.

핵심 기능

  • 나라장터 공공데이터 API 연동 및 공고·개찰자료 수집
  • 엑셀·CSV 낙찰데이터 첨부 및 AI 분석
  • 분석 결과와 입찰 정보를 정리한 입찰대장 Excel 생성

사용 순서

  • ① 나라장터 공공데이터 API 인증키 등록
  • ② 조건에 맞는 공고·개찰자료 수집
  • ③ 보유한 낙찰데이터 첨부 후 AI 분석 실행
  • ④ 분석 결과 확인 후 입찰대장 Excel 생성

※ AI 분석 결과는 입찰 판단을 돕는 참고자료이며, 최종 투찰 결정은 사용자가 직접 확인합니다.
