# 나라장터 AI 낙찰 예측 모바일

나라장터 공공데이터를 가져오고, 첨부한 낙찰데이터를 분석해 입찰대장 엑셀까지 만드는 모바일 입찰 업무 앱입니다.

## 핵심 기능

- 나라장터 공공데이터 API 연동 및 공고·개찰자료 수집
- 엑셀·CSV 낙찰데이터 첨부 및 AI 분석
- 분석 결과와 입찰 정보를 정리한 입찰대장 Excel 생성

## 사용 방법

1. 나라장터 공공데이터 API 인증키를 등록합니다.
2. 조건에 맞는 공고와 개찰자료를 수집합니다.
3. 보유한 낙찰데이터를 첨부하고 AI 분석을 실행합니다.
4. 분석 결과를 확인하고 입찰대장 Excel 파일을 생성합니다.

> AI 분석 결과는 입찰 판단을 돕는 참고자료이며, 최종 투찰 결정은 사용자가 직접 확인해야 합니다.
