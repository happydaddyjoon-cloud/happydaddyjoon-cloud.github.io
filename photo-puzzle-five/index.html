포토퍼즐 파이브

사진과 추억을 직접 움직이며 완성하는 반응형 슬라이딩 퍼즐

포토퍼즐 파이브(PhotoPuzzleFive)는 기본 이미지 27장과 사용자가 갤러리에서 선택한 사진을 3×3 부터 8×8 까지의 슬라이딩 퍼즐로 즐길 수 있는 Android 앱입니다. 휴대전화와 태블릿, 세로·가로 화면에 자동으로 대응합니다.

핵심 기능

  • 사진 선택 추억 사진·추천 이미지·특별한 날·사계절 이미지와 Android 공식 사진 선택기를 지원합니다.
  • 퍼즐 맞춤 갤러리 사진 전체를 자르지 않고 4:3 퍼즐판 규격에 맞춰 자동 확대·축소합니다.
  • 직관적 조작 터치·더블 탭·끌기로 조각을 이동하며, 타이머 일시정지·다시 섞기·원본 보기를 제공합니다.
  • 완성 경험 배경음악과 이동 효과음, 성공·실패 캐릭터 애니메이션, 축하 팡파레와 닫기 버튼을 제공합니다.

이용 순서

01사진 선택 → 갤러리 또는 기본 이미지에서 퍼즐 사진을 고릅니다.
02난이도 선택 → 3×3~8×8 중 원하는 퍼즐 크기를 선택합니다.
03퍼즐 시작 → 빈칸을 향해 조각을 누르거나 끌어 이동합니다.
04완성 확인 → 기록과 축하 이벤트를 확인하고 다시 하기 또는 다음 난이도를 선택합니다.
